# Citisoft Marketing Website — UI kit

A faithful, brand-consistent recreation of the Citisoft Solutions public marketing
site. Demonstrates the light/dark rhythm, the signature blue gradient, the serif
lede voice, and the RFQ product spotlight (magenta accent).

> **Note:** No production website or Figma was provided. This is an original,
> on-brand sample assembled from the brand brief + design-system primitives — not a
> copy of an existing page. Reconcile against the real site if/when available.

## Run
Open `index.html`. It loads `styles.css` + the compiled `_ds_bundle.js`, then the
section files. (The bundle is generated by the design-system compiler; if it 404s,
the system hasn't been compiled yet.)

## Sections (files)
- `SiteNav.jsx` — sticky glass nav with logo, links, sign-in, primary CTA.
- `Hero.jsx` — **dark** hero: eyebrow, gradient headline word, serif lede, trust
  stats, and a floating product-UI panel.
- `Features.jsx` — light feature grid built from `FeatureChip`.
- `Products.jsx` — **dark** product family section spotlighting the RFQ Platform
  (magenta accent) + a live quote-comparison mock.
- `Insights.jsx` — light editorial grid with working `Tabs` filter.
- `SiteFooter.jsx` — gradient CTA band + dark mega-footer.
- `icons.jsx` — inline Lucide-path `Icon` helper (window global).

## Interactions
- "Start an RFQ" (nav, hero, products, CTA) opens a working `Dialog` with a sample
  RFQ form (`Input` / `Select`).
- Insights tabs swap the article set.
- Cards and product tiles lift on hover.

## Components used
`Logo`, `Button`, `Badge`, `GradientText`, `FeatureChip`, `Card`, `Tabs`,
`Dialog`, `Input`, `Select`.
